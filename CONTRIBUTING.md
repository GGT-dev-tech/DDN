# Contributing

## Branching Model
- `main`: Production-ready code.
- `develop`: Pre-production / integration.
- `feature/*`: New features.
- `hotfix/*`: Production fixes.

## Commit Guidelines
Use semantic commits:
- `feat(module)`: New feature
- `fix(module)`: Bug fix
- `docs(...)`: Documentation
- `test(...)`: Adding missing tests
