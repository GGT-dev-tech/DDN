# Base de Conhecimento (Knowledge Base)

Esta pasta contém a Base de Conhecimento privada da empresa (ex: notas do Obsidian, procedimentos internos, contratos, manuais originais, referências B2B).

> [!WARNING]
> Os documentos brutos não sintetizados armazenados aqui **NÃO fazem parte do repositório** e são ignorados pelo `.gitignore`.

A documentação oficial derivada (sintetizada a partir desta base) que de fato deve guiar a implementação sistêmica encontra-se em:
* `docs/company`
* `docs/business`
* `docs/architecture`
